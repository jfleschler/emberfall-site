# Emberfall website

Official landing, support, and privacy pages for Emberfall: Hollow Woods.

Published at https://jfleschler.github.io/emberfall-site/ using GitHub Pages from the root of `main`. This repository contains only the public website; game source is maintained separately.

Static HTML and CSS, with locally hosted fonts and artwork. No build step, analytics, or third-party scripts. Preview with `python3 -m http.server 8080`.
